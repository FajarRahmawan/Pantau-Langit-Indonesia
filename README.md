# Pantau-Langit-Indonesia
Download data kualitas udara (CAMS), hotspot kebakaran (NASA FIRMS), cuaca (NOAA GFS) dan citra satelit (NASA GIBS) untuk wilayah Indonesia Tersedia analisis ISPU sesuai Permen LHK 14/2020 dengan statistik per wilayah administrasi. Membutuhkan API KEY untuk menjalankan aplikasi ini.
